# TechStore — Ecommerce (React) | Итерация 3

Третья итерация проекта интернет-магазина. 

В данной версии фокус сделан на **работу с побочными эффектами**.
## Что реализовано (Итерация 3)

*   **Живой таймер (Управление интервалами):**
    *   создан интерактивный баннер с обратным отсчетом;
    *   использование хука `useEffect` для подписки на `setInterval`;
    *   строгая очистка (cleanup) интервала при остановке или размонтировании для предотвращения утечек памяти;
    *   логика паузы, возобновления и рестарта таймера;
    *   блокировка элементов управления при истечении времени.

## Запуск проекта

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Mesenyov/ecommerce-react-2.git
   ```
2. Перейдите в директорию проекта:
   ```bash
   cd ecommerce-react-2
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите сервер для разработки:
   ```bash
   npm run dev
   ```
Откройте в браузере `http://localhost:5173`
